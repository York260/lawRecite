# 律刃（lawRecite）

用「注音首」背法條的網頁遊戲。開啟後是首頁：上方顯示登入身分與戰績，下方選擇逐字背誦、關鍵字填空、今日複習或雙人對決。目前收錄《警察人員人事條例》（民國 114 年 04 月 25 日修正，共 52 條）與《警察職權行使法》（民國 100 年 04 月 27 日修正，共 32 條），點首頁書封上會搖的朱印打開「印譜」挑一顆換法規，或在練習畫面上方切換；各法規的進度、複習分開記錄。

## 兩種模式

- **逐字背誦**：整條條文全部挖空，每個字只要打出它的**第一個注音**就會出現。
  打錯的字會以紅底標出；背完一條按「下一條」。
- **關鍵字填空**：只挖關鍵字（數字、官等、機關、法律名稱、法律用語……），
  其餘文字照常顯示，一樣用注音首輸入。挖空程度分「少／中／多」三級（全法約 31%／52%／72% 的字）。

## 兩種輸入方式

- **注音**：打每個字的第一個注音（見下方）。
- **語音**：按麥克風，直接把條文唸出來。辨識出的字會和條文逐字對齊：
  同字或同音字（不分聲調）算對；唸成別的字或漏唸的字標紅底。
  「第28條」「40歲」這類阿拉伯數字會自動換成條文寫法再比對。
  關鍵字填空時可以整句唸，也可以只唸空格的詞。背完一條說「下一條」即可換條。
  語音辨識使用瀏覽器內建功能（Chrome、Edge，或 iPhone／Mac 的 Safari），需要網路與麥克風權限。

共同功能：

- 手機：畫面下方內建注音鍵盤（不會叫出手機系統鍵盤），另有「提示」與「⌫」退回鍵。
  按鍵是「放開手指才輸入」：按住會放大顯示該注音，按錯可滑到旁邊的鍵再放開，滑出鍵盤放開則取消。
  在「設定」可切換鍵盤排列（大千／ㄅㄆㄇ順序，後者每列 8 鍵、按鍵較寬／三星注音，同三星手機鍵盤，聲調位置換成提示與 ⌫，法條用不到的 ㄥ 換成 ㄦ）、按鍵大小（標準／大／特大）與按鍵震動。
  聲母、介音（ㄧㄨㄩ）、韻母以不同底色區分。
- 白天／黑夜模式：右上角按鈕切換，或在「設定」選擇跟隨系統。
- 條文字級：在「設定」裡用「A− / A＋」調整（80%～175%），會記住。
- 電腦：直接用實體鍵盤的大千注音鍵位（`1`=ㄅ、`q`=ㄆ、`a`=ㄇ、`z`=ㄈ…），不需切換輸入法。
  `Backspace` 退回一字、空白鍵提示、按住 `Ctrl` 暫時看原文（同「原文」，該次不計成績）、`Enter` 完成後到下一條、`[` `]` 切換上一條／下一條。
- 多音字（例如「行」ㄒ／ㄏ）任一讀音的注音首都算對。
- **原文**：條文卡片左上角「原文」按鈕，打開後空格裡會淡淡顯示原字，可以照著打（適合初學）。會記住開關；
  看過原文的那一次不計成績、不影響間隔複習。對決中不能使用。
- 「打錯要重打」：開啟後打錯會停在原處，打對才前進（那個字仍會留下紅底記錄）。
- 每條都有中文條名（例如第 4 條「官職分立」），顯示在條文標題下與條文選單裡；名稱定義在 `scripts/titles.py`，其中標「筆記」的取自學長筆記。
- 每條的最佳正確率會記在瀏覽器裡，條文選單上會顯示 ✓ 或百分比。
- **間隔複習**：背完一條若有打錯或用了提示，會自動排入複習，隔 1 天、3 天、7 天各複習一次；
  每次都要全對才進到下一階段，又錯就從 1 天重來，7 天那次也全對即視為熟記。
  按「複習 N」按鈕一次把今天到期的條文背完；條文選單上以 ⟳ 標示到期的條文。

## 使用

線上版（GitHub Pages）：https://york260.github.io/lawRecite/


直接用瀏覽器開啟 `index.html` 即可，不需要伺服器。
想傳到手機離線使用，可以產生單一檔案：

```sh
python3 scripts/build_single.py   # 輸出 dist/lawrecite.html
```

## 雙人對決

首頁按「雙人對決」→ 用 Google 或訪客身分登入 → 輸入暱稱 →「建立房間」，把 4 碼房號或邀請連結傳給朋友，對方按「加入」後倒數 3 秒開打。
開房時可選法規、模式（逐字背誦／關鍵字填空＋挖空程度）與篇幅（短約 160 字／標準約 260 字／長約 400 字），加入者照房主設定。
兩人背同一串隨機條文，每答對一字從自己的血條劈出一道墨色刀芒砍向對方血條；每連對第 5、10、15… 字是朱紅刀氣，該字傷害 ×2；
整條全對觸發「刀氣縱橫」全畫面特效並額外造成 10 字份的傷害；連對第 11 字起傷害 ×1.25、第 21 字起 ×1.5；血量先歸零者輸，都背完則比剩餘血量。
對決中可隨時在條文卡片右上角切換「注音／語音」，不會重來、保留進度與連斬。對決畫面只顯示條號與條名，不顯示章名、字數與對錯統計。
對戰中有人斷線（切 App、關螢幕、換網路，甚至關掉網頁）會等 60 秒讓他回來（這段時間攻擊暫停，打字不算傷害）；關掉網頁的人 45 秒內重開，首頁會跳出「回到對戰」，回到原本打到的那個字接著背。超過時限判負，按投降則對手立即獲勝。
需從 GitHub Pages 網址開啟（claude.ai 頁面內無法連線），且 Firebase 後台要啟用 Google 與匿名兩種登入方式。技術設計見 [docs/duel-design.md](docs/duel-design.md)，
資料庫安全規則在 [firebase/database.rules.json](firebase/database.rules.json)。

## 資料

- `data/source/police-personnel.txt`：由全國法規資料庫 PDF 以 `pdftotext -layout` 轉出的原文。
- `scripts/keywords.py`：關鍵字填空的詞表與規則（等級 1～3）。
- `scripts/build_data.py`：解析條文、以 [pypinyin](https://github.com/mozillazg/python-pinyin) 計算每個字的注音首，
  並套用關鍵字等級，輸出 `data/laws.js`；另輸出語音模式用的同音字表 `data/sounds.js`（Big5 常用字＋條文用字）。

修改任何 CSS／JS／資料後，執行 `python3 scripts/stamp_assets.py` 更新 `index.html` 裡的版本號（`?v=…`）與 `version.json`，
避免瀏覽器拿到「新頁面配舊樣式」的快取。網頁開啟、切回前景時，以及開著時每 2 分鐘會比對 `version.json`，發現自己是舊版就自動換新；
只在首頁、條文還沒開始打或剛背完時才換，練習中會回到同一條，對戰中不打斷。

修改詞表或新增法規後重新產生資料：

```sh
pip install pypinyin
python3 scripts/build_data.py
```

新增其他法規：把轉出的文字檔放進 `data/source/`，在 `build_data.py` 的 `SOURCES` 加一筆（含簡稱 `short` 與首頁印章四字 `seal`），
在 `scripts/titles.py` 補上條名、`scripts/keywords.py` 補上關鍵字，網頁會自動出現法規選單。
